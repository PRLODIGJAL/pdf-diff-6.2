# PDF差异对比工具 6.2

> 自带运行环境：拷到任何电脑、双击就能用，不用装 Python、不用联网。

## 怎么启动

双击「启动PDF差异对比工具」（Mac 是 `.command`，Windows 是 `.bat`）。
第一次打开会先跑几秒自检，之后秒开。

启动器自带体检：权限丢了、从网上传过来被系统拦了，它都会自己修好。
**没有别的步骤，也不需要再点第二个文件。**

## 怎么用

1. 把两份文件拖进窗口 —— **拖进来就能看**原件，能翻页缩放，类型当场判定
2. 点「开始对比」
3. 右上角三个按钮换看法：并排 / 滑动（中间一根线左右拖）/ 叠加（两版来回闪）

## 这版有什么

- **自带运行环境**（6.2 新增）：以前靠机器上装的 Python，换台电脑就要重新配；现在整个运行环境在包里，拷过去就能开
- **三种看法**：并排双栏、单幅滑动、叠加闪烁（底栏最右边调快慢，可选「关闭」改手动切换）
- **修掉短串漏标**：以前改一两个字会被判成「整段新增」，现在只框那两个字
- 四色图层：删减（红）/ 新增（绿）/ 位移（浅蓝）/ 待判定（紫），三个勾可以各自开关
- **四条硬门槛**：只能同格式比、页数必须相同、纯扫描件不比、拼接 PDF 里的扫描页自动跳过
- 标题行最右端四格类别（纯原生 / 混合型 / 图片转曲 / 扫描件），鼠标停上去看细分

## 注意

- 门槛变严了是故意的：跨格式、页数不同时刷出来的差异大半是「转换差」，不是「你改的」
- 纯白底的图片 PDF 不会被误判成扫描件，照旧能比
- 比对过程**完全不联网**，两份文件的内容不会离开这台电脑

## 打不开 / 报错

- **双击后一闪就没 / 提示运行环境不对**：再双击一次启动器，它会把运行环境重新识别一遍
- **Mac 提示「无法打开」**：到「系统设置 → 隐私与安全性」点一次「仍要打开」，以后就不问了
- **Windows 提示「已保护你的电脑」**：点「更多信息」→「仍要运行」，只此一次
- **换了电脑或挪了文件夹之后**：直接双击启动器就行，别的什么都不用做

## 更新记录

- **2026-11-09｜修掉 Windows 上「自检全绿、界面却打不开」**
  双击启动器，六项自检全 OK，界面刚搭一半就退出，提示 `bad button number "6"`。
  原因是横向滚轮绑了鼠标 **6/7 号键位**，而 Windows 自带的界面库（Tk 8.6）只认 1~5 号，
  解析事件那一刻就报错；Mac 那套库是 9.0，同样的写法从来不报 —— 所以这问题只在 Windows 露头。
  现在改成「能绑就绑、绑不上跳过」，不影响任何功能（Windows 的横向滚动本来就靠 Alt+滚轮）。
  **对比逻辑一个字节没动。**
